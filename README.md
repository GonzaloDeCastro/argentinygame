# Batallas Argentinas

Juego de estrategia por turnos, al estilo Fire Emblem, sobre batallas de la historia argentina.
Se juega en el navegador: es un solo archivo (`index.html`), sin instalar nada.

## Cómo jugar

Abrí `index.html` en el navegador (o la página de GitHub Pages del repositorio) y elegí una batalla.
El juego trae un instructivo (botón o tecla **H**) con los pasos, el triángulo de armas y consejos de estrategia.

- Clic en una unidad azul, luego en una casilla para moverla, y elegí **Atacar** o **Esperar**.
- Pasá el mouse sobre un enemigo para ver el pronóstico del combate.
- **T** muestra la amenaza enemiga. **Esc** o clic derecho vuelven un paso atrás.
- Hay tres dificultades: Fácil, Normal y Difícil.

## Notas

- Los diálogos son una dramatización: no son citas textuales de los personajes históricos.
- Todo el arte y el sonido se generan por código (canvas y Web Audio).
- El sonido es opcional y está apagado por defecto.
